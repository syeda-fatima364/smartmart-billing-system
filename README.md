# SmartMart Billing System 🛒

A console-based billing system for a grocery store developed in C++.

The program calculates the total purchase amount and applies discounts based on:
- Total bill amount
- Whether the customer is a regular customer

## Features
- Customer information input
- Product entry system
- Automatic bill calculation
- Discount system
- Final bill generation

## Discount Policy
| Total Amount | Discount |
|--------------|---------|
| < 5000 | 0% |
| 5000 – 9999 | 5% |
| 10000 – 19999 | 10% |
| ≥ 20000 | 15% |

Regular customers receive **an additional 3% discount**.

## Concepts Used
- Functions
- Loops
- Conditional statements
- Input validation

## How to Run

Compile the program:

g++ smartmart-billing.cpp

Run the program:

./a.out
